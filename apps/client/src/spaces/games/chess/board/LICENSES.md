# Chess piece assets

This folder embeds the **Cburnett** SVG chess piece set (as used by lichess) as
inline SVG strings in `chess-pieces-svg.ts`.

## Source

- Upstream files: `public/piece/cburnett/*.svg` from the `lichess-org/lila` repo.
