# Contributing

This product is **source available, not open source**. The repository is public
so the code can be read; it is not an invitation to contribute, and
[`LICENSE`](LICENSE) grants no right to use, modify or redistribute it.

## Outside contributions are not accepted

- Pull requests from people who have not been explicitly authorized in writing
  by the copyright holder will be closed without review.
- Do not send patches, code suggestions or designs by any other channel
  either. Unsolicited material cannot be used, and sending it creates no
  obligation for the project.
- Opening an issue to report a bug in the public app is welcome. Do not
  include code you want merged.

If you have been authorized to contribute, the terms of that authorization
(including ownership of what you contribute) are the ones agreed in writing
with the copyright holder.

## Security issues

Never report a vulnerability in a public issue or pull request. Follow
[`SECURITY.md`](SECURITY.md).

## Pull requests from forks

Continuous integration needs secrets that GitHub never gives a pull request
from a fork, so such a pull request's checks stop at setup with that reason.
This is expected, and is not a fault to report.
