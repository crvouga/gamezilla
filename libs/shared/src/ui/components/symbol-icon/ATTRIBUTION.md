# Font Awesome

Icons in this folder are **vendored SVG path data** from **Font Awesome Free 7.x** (`svgs-full/solid`), converted to [`react-native-svg`](https://github.com/software-mansion/react-native-svg) components.

- **Project:** [Font Awesome](https://fontawesome.com) by Fonticons, Inc.
- **Source tree:** [FortAwesome/Font-Awesome `7.x/svgs-full`](https://github.com/FortAwesome/Font-Awesome/tree/7.x/svgs-full)
- **License:** [Font Awesome Free license](https://fontawesome.com/license/free) — Icons: **CC BY 4.0**; Fonts: **SIL OFL 1.1**; Code: **MIT**.
