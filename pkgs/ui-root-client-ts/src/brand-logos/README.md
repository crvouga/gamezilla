# Vendor artwork

Google’s unmodified standard-color gradient G is downloaded from
[Google Identity](https://developers.google.com/static/identity/images/g-logo.png).
It is displayed at 20px in sign-in controls, without filters or recoloring.
The mark and social button palette follow the
[branding guidelines](https://developers.google.com/identity/branding-guidelines)
reviewed on 2026-10-30. Vendor artwork is an intrinsic-color exception to neutral chrome.
