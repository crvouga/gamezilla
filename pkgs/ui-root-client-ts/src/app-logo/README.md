# Gamezilla identity

A stepped emerald monster silhouette, paired square eyes and a G-shaped smile
make the product recognizable at header size. The Unbounded wordmark stays in
the semantic text color. The intrinsic artwork is a narrow brand exception to
neutral application chrome. Mark-only variants keep the accessible product name.
The logo is an image role, never the page heading. Size, wordmark visibility and
semantic wordmark color are the public controls; all are shown in the colocated stories.
