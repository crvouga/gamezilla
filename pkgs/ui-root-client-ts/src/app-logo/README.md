# Product identity

The host supplies the product name and artwork through `name` and `markSrc`.
The default artwork is a neutral application mark for reusable compositions;
production hosts read their artwork from identity configuration. The intrinsic
artwork is a narrow color exception to neutral application chrome. Mark-only
variants keep the accessible product name. The logo is an image role, never
the page heading. Artwork, size, wordmark visibility and semantic wordmark
color are shown in the colocated stories.
